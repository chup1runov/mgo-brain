# Open Questions / Unknowns

These are intentionally unresolved. Do not fill them from memory or a similar vehicle without evidence.

## Factory electrical / CAN

- Where exactly is the factory BFI CAN pair on this vehicle?
- Connector / pin numbers?
- Wire colors?
- Bus resistance/topology?
- Bitrate?
- Standard vs extended identifiers present?
- Which cluster/body values are broadcast?
- Is engine RPM present anywhere on factory CAN or another stock signal?

## Engine sensors

- Exact OEM oil-pressure-switch thread?
- Best safe oil pressure/temp take-off location?
- Independent coolant sensor mounting location?
- Actual hose/adaptor dimensions?
- Any stock tach/rev-counter signal available?

## CVT / gearbox

- Best repeatable fixed points for temperature sensors?
- Which temperatures correlate with belt/variator condition?
- Best vibration sensor mounting point?

## Power / packaging

- Exact permanent Brain mounting location?
- Measured sleep current of final hardware?
- Wake source / ignition strategy on installed unit?
- Final fuse value after measured consumption?
- Cable lengths and routing?

## Display

- Phone-only first release or dedicated display immediately?
- Final display size?
- Mounting position / glare / night brightness?

## Network / security

- Dedicated vehicle hotspot vs existing phone hotspot?
- Authentication layer before any remote access?
- Remote VPN requirement?

## AI

- Manual ChatGPT context upload vs automatic API integration?
- Voice provider / audio route?
- Data retention policy for AI requests?

## Rule

Close an item only with a link to evidence, commit, session, measurement or ADR.
