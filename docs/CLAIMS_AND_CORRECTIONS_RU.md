# Корректировки прежних утверждений

Дата: 19.09.2026. Основание: чтение актуального кода, воспроизводимые тесты, доступный чат; где требуется механическое подтверждение — оно не подменяется догадкой.

| Прежнее впечатление из чата/документов | Корректное состояние |
|---|---|
| «Всё ПО до машины полностью готово», 70–80% | Процент не обоснован. Есть полезный исполняемый прототип, но существуют программные и интеграционные блокеры |
| «80 сигналов уже есть у машины» | Это реестр планируемых каналов, часть синтетическая, часть производная, физические источники не проверены |
| «BFI/CAN в каталоге означает доступ ко всем параметрам» | Каталожная запись не подтверждает состав сообщений и даже точки подключения конкретного экземпляра |
| «Добавим OBD-разъём — появится OBD-II» | Корпус разъёма не создаёт ECU/PID/DTC. MDP-1 только проектный сервисный разъём |
| «В Python нет send — шина пассивна» | CAN-контроллер может выдавать ACK/error frames. Нужен настоящий driver/controller listen-only |
| «Ключ OFF, значит можно измерять сопротивление» | Питание модулей может сохраняться. Сначала безопасно изолировать питание по процедуре и проверить отсутствие напряжения; не мерить Ω на питаемой цепи |
| «Распиновка AutoPi в чате окончательная» | В сообщениях менялись названия каналов. Не использовать это как монтажную карту без документа конкретной ревизии |
| «Давление и температура масла одним датчиком в тройнике почти идеальны» | Геометрия, пульсации, вибрация, герметичность и застойное масло могут искажать показания; место нужно обосновать |
| «Наружного диаметра патрубка достаточно для адаптера» | Для вставки важны фактический внутренний размер, материал/крепление, поток и допустимые нагрузки |
| «RPM / скорость — истинное CVT ratio» | Это размерный индикатор rpm/(km/h), не безразмерное передаточное отношение. Стоп/сцепление/колёса/редуктор/пробуксовка важны |
| «Вибрация двигателя минус вибрация кузова» | Простое вычитание без общей ориентации, синхронизации, полосы и модели передачи не отделяет источник |
| «500A SmartShunt достаточно для анализа пика стартера» | Допустимый ток и полоса/частота измерения — разные свойства; нужен отдельный проверенный быстрый канал |
| «Любой отказ любой добавленной детали не влияет на машину» | Это цель проектирования. Шунт, фитинг масла, врезка ОЖ и проводка имеют физические последствия при отказе |
| «20 поездок/запусков достаточно для доказанной нормы» | Это параметр алгоритма, не гарантия. Реальная база требует квалификации, условий и проверки на дрейф |
| «NORMAL означает механически исправно» | Пока означает отсутствие сработавшего правила при имеющихся данных; не покрывает неизвестные неисправности |
| «Тормоза/шины полностью диагностируются» | Есть поля/общая оценка доступности. Проверенные пороги и полноценные диагностические правила не реализованы |
| «Bench проверяет CAN, Modbus и SmartShunt как устройства» | v0.5.9 напрямую создаёт SourceUpdate. Это тест программных контрактов, не полный wire-protocol/device E2E |
| «Источник пропал — предупреждение должно очиститься» | Нет. Отсутствие измерения не подтверждает восстановление; активная тревога удерживается с признаком потери наблюдения |
| «Parquet никогда не влияет на live-путь» | До аудита вызывался синхронно в общем цикле; исключение могло остановить сбор. В аудитной версии вынесен в очередь/поток с наблюдаемым отказом |
| «PWA и wake lock работают на любом mgo.local» | Требуются браузерные secure-context условия; обычный LAN HTTP не гарантирует service worker/wake lock |
| «Ask MGO уже голосовой ChatGPT в машине» | Пока текстовый evidence gateway; локально шаблонный ответ, облако опционально. Голос не реализован |
| «Подписка ChatGPT автоматически включает API для автомобиля» | ChatGPT и API — отдельные продукты/настройки; API-ключ и биллинг нужны отдельно при выборе облака |
| «Все инструкции уже сохранены PDF в репо» | В доступном текущем наборе есть ссылочный реестр и текстовые пересказы. Не заявлять наличие оригинального PDF, которого нет в Git |

Исправления являются частью истории, а не основанием переписывать старые git-коммиты. Старые схемы и демонстрационные числа не становятся подтверждённой конфигурацией.
