## Заводские документы, которые упоминались

- M.Go / Dué 2017 Owner Manual, Ref. 1413289 (07/2017), семейство MGO4/DUE3.
- MGO4/P98 exploded parts catalogue и электрические разделы BFI/CAN.
- Lombardini LDW502 Automotive Service Manual `ED0053027270_R02_MO_FOCS_502_auto_GB.pdf`.
- LDW502 parts document с упоминанием Progress/citycar.
- CVTech installation/service materials.
- Более старый Microcar M.Go workshop manual примерно 2008: не переносить его детали на 2017 без проверки.

URL находятся в REFERENCES.md. Сам факт URL не подтверждает доступность, редакцию, применимость или право публичного распространения. Не добавлять внешние PDF с придуманным checksum. Для оригинала нужны реально полученные bytes, SHA-256, издатель, редакция и разрешённый способ хранения.

## Что намеренно не перенесено

Не относящиеся к MGO Brain чаты и проекты; персональные маршруты/секреты; регистрационные документы; выдуманные распиновки; повторные обещания процентов готовности; старые цены как актуальный прайс; выводы о реальной исправности, основанные на симуляторе.

## Перед удалением чата

Для продолжения инженерной работы читать START_HERE_RU.md достаточно. Для побитового хранения оригинальных изображений/вложений сохраните резервный комплект. Git history сохраняет историю кода, но не заменяет оригиналы внешних руководств и вложений, если они явно перечислены здесь как не включённые.
