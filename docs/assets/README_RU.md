## Что хранить в GitHub

Рекомендуемый порядок:

1. **Лучший вариант:** исходные PNG как отдельные файлы, например `docs/assets/mockups/`, с их SHA-256.
2. **Опционально:** полный ZIP прикрепить как GitHub Release asset, если нужен единый побитовый резервный комплект.
3. Не рекомендуется коммитить ZIP прямо в обычное source tree: он непрозрачен для diff, дублирует PNG и исторический v0.1, увеличивает размер Git history.

Исторический `mgo-brain-v0.1.zip` не требуется для восстановления текущего кода — история кода уже находится в Git.
