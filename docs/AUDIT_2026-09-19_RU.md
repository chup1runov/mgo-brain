## Подтверждённые дефекты и исправления аудитной ветки

| Дефект | Исправление / проверяемое поведение |
|---|---|
| Правила могли вычислять по STALE/INVALID/SUSPECT/UNVERIFIED | Единый проверенный accessor; сырое показание сохранено отдельно |
| NaN/Inf могли попасть в состояние/JSON/статистику | Непригодный scalar -> INVALID без ложного числа |
| Отказ одного датчика проигрывал его старому GOOD-значению | Последнее состояние хранится отдельно по каждому источнику; новый отказ заменяет старое значение |
| Резервный источник не удерживался | Агрегатор сохраняет кандидатов и выбирает свежий резерв |
| Молчание всех источников не старило данные | Периодическая проверка даже без сообщений |
| EOF/исключения SourceMux оставляли зависший потребитель | EOF и ошибки наблюдаемы, закрытие ограничено по времени |
| Все подсистемы UNKNOWN, overall NORMAL | Общий статус UNKNOWN и явное покрытие |
| `/health` возвращал ok при мёртвом сборе | Readiness и 503 при отсутствии готовности; фактическое происхождение данных |
| Пропавшее измерение очищало тревогу | Удержание активной тревоги до пригодного свидетельства восстановления |
| Повышение severity не создавало переход | UPDATED как отдельное событие |
| История/Parquet работали перед live-alerts и могли оборвать цикл | Локальные правила раньше хранения; bounded очередь и отдельный worker для I/O; видимые runtime errors |
| Базы симулятора и машины смешивались | Раздельные `simulator/bench/vehicle` namespaces; старая база не уничтожается |
| Пустой Modbus-ответ превращался в GOOD zero/False | INVALID/None |
| VE.Direct не проверял binary checksum | Byte parser с checksum; legacy text-only результаты UNVERIFIED |
| Factory CAN wrapper не проверял режим контроллера | Проверка Linux link LISTEN-ONLY перед физическим factory-open; Sensor CAN отделена |
| Replay EOF мог крутиться бесконечно | Явное exhausted и завершение decoder stream |
| DBC draft угадывал DLC по изменившемуся байту | Использование наблюдённой единственной длины; пропуск неопределённой |
| Запросы API не ограничены по размеру | Body cap и Origin-проверка браузерных записей; это не полноценная аутентификация |
| Экран показывал устаревшие числа как live | Скрытие непригодных чисел/таймаут WebSocket, маркировка синтетического режима |
| AI игнорировал язык и использовал непроверенное имя модели по умолчанию | Язык проходит через evidence; явная настройка модели; bounded timeout/output, локальный fallback |
| Docker context/backup могли захватить лишнее | Исключение секретов/runtime из build context; ограничения backup output и symlinks |

Фактический итог этих исправлений определяется финальным workflow и сохранённым машинным отчётом, а не этой таблицей намерений. Скрипты одноразовой миграции не должны остаться необходимой частью запуска.
