# Что ещё нужно сделать

Контрольная точка после v0.5.11 public-release cleanup. Глубокий аудит v0.5.10 остаётся исторической базой. Приоритет не равен очередной большой версии; каждую задачу закрывать доказательством и тестами.

## До подключения к реальному автомобилю

| Приоритет | Задача | Критерий приёмки |
|---|---|---|
| P0 | Проверить аппаратное питание, нагрузку, выбросы и sleep/wake на выбранной ревизии компьютера | Испытания старта/просадки/отключения/длительной стоянки с измеренным потреблением |
| P0 | Подтвердить входные уровни, импедансы, изоляцию, сигнальные земли и работу аварийных OEM-цепей | Схема и измерения, а не прямое подключение 12V к GPIO |
| P0 | Заводская CAN: подтверждённые провода, bitrate, топология, гарантированный silent mode | Пассивный лог, отсутствие вмешательства в штатную работу |
| P0 | Перенести прототипные пороги в конфигурацию и связать с проверенным руководством/датчиком/условиями | Для каждого правила источник, условия работы, задержка/гистерезис, неопределённость |
| P1 | Реальные протокольные E2E-тесты, не только SourceUpdate | vcan/cantools, реальные RS485-ответы, VE.Direct байты, отключения/повреждения/частоты |
| P1 | Отказоустойчивая история после отключения питания | Восстановление незакрытого JSONL, атомарная финализация Parquet, отсутствие потери исходника при ошибке |
| P1 | Расчёт дистанции и статистики с неравномерным временем | Трапецеидальное интегрирование, явные пробелы, отсутствие интеграции через большой gap |
| P1 | Квалификация baseline и его устойчивость | Когортирование температуры/RPM/нагрузки; нулевая дисперсия; миграция/обслуживание; эталон не меняется из-за лимита чтения последних записей |
| P1 | Ограничения real-time/ресурсов | Длительная нагрузка, переполнение очереди, переподключение драйверов, предсказуемый shutdown даже при зависшем файловом I/O |
| P1 | Защита сети перед удалённым доступом | Аутентификация, TLS/VPN или закрытая сеть, rate limits; текущая Origin-проверка не является авторизацией |
| P1 | Проверка справедливости NORMAL | Для шин/тормозов различать наличие телеметрии и диагностику; покрытие/неизвестные условия видны пользователю |
| P2 | Полнота русской локализации | Все пользовательские сообщения, отчёты и динамические состояния; LAB может показывать точные технические идентификаторы |
| P2 | Семантические типы DBC | D/N/R и bool не превращаются бесконтрольно в float; mappings/types/units/ranges подтверждены |
| P2 | CAN FD/RTR/error/extended-low-ID | Или явно отвергать, или хранить флаги/формат без потерь; текущий исследовательский путь ориентирован на классический data CAN |
| P2 | Численное discovery | Не переоценивать множество CAN кадров, сопоставленных одному GPS sample; out-of-sample проверка и временной сдвиг |
| P2 | Голос и поиск по мануалам | Реально работающий интерфейс/индекс с provenance, а не пустое имя функции |

Аудит устраняет выявленные дефекты в пределах проверяемого прототипа, но не объявляет эти задачи выполненными.

## Когда пользователь вернётся к машине

1. Фоторазведка BFI/предохранителей/жгутов/аккумулятора/двигателя без случайного отключения и прокалывания.
2. Безопасная проверка питания и CAN-кандидата; неизвестные цепи не измерять наугад.
3. Компьютер сначала на защищённом стенде; затем короткая пассивная CAN-запись и её replay.
4. Повторяемые эксперименты с одним изменяемым состоянием. Сигнал в production DBC — только после подтверждения.
5. Финиш A: частичная реальная приборка, с явными пробелами. Не покупать все датчики ради заполнения картинки.
6. Датчики двигателя/АКБ/CVT по отдельным схемам, проверкам и закупочным условиям.
7. Длительные поездки, обслуживание, контроль базовой нормы, затем опциональные TPMS/салон/камера/постоянный экран.

## Не покупать и не делать автоматически

Не покупать финальный экран, датчики/переходники неизвестного размера, все RS485-модули и AutoPi исключительно по старой ориентировочной цене из чата. Не менять прошивку, ограничения скорости, стартер/накал/тормоза, не подавать искусственные CAN сообщения в заводскую шину. Не включать облачные расходы и публикацию персональной телеметрии по умолчанию.
