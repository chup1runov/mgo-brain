# Project state / текущее состояние

Текущая программная точка **v0.5.11 — public release cleanup**, 25.09.2026. Базовый глубокий аудит v0.5.10 от 19.09.2026 остаётся исторической доказательной точкой.

Начало: [START_HERE_RU.md](../START_HERE_RU.md). Полная передача: [CHAT_HANDOFF_RU.md](CHAT_HANDOFF_RU.md).

Исполняемый программный прототип существует; старые функциональные тесты дополнены регрессиями на потерю качества/источников, EOF, отказ хранения, происхождение данных и границы протоколов. Результаты сохраняются в [аудитном архиве](audit/2026-09-19/README.md).

Физическая интеграция не выполнена. Не подтверждены CAN-пара/bitrate/DBC, GPIO/электрические подключения, резьбы/патрубки, power management и монтаж конкретных устройств. Полноценный protocol-level bench, квалифицированные диагностические пороги, crash recovery, сложная baseline-статистика и защищённый удалённый доступ ещё требуют работы. Wheel/install теперь включает default config и web assets и проверяется отдельным CI smoke.

Не считать физическую разведку единственным оставшимся блокером. Пользователь ранее откладывал её; полезная программная работа перечислена в [REMAINING_WORK_RU.md](REMAINING_WORK_RU.md).
