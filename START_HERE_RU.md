Это самостоятельный проект телеметрии и диагностики Microcar M.Go. Не переносите сюда названия, задачи или договорённости других проектов владельца.

## Что является результатом

В GitHub находятся исполняемый прототип, интерфейс, тесты, история решений, план интеграции, ограничения и материалы для продолжения работы. Проект пока **не установлен и не проверен на автомобиле**. Наличие адаптера или зелёного CI не подтверждает электрическую совместимость, точность диагностики либо соответствие автомобильным стандартам безопасности.

## Правила, которые нельзя потерять

- Цель: один логический «мозг», собирающий максимум полезных данных с разных систем; не новая управляющая ЭБУ.
- Штатные запуск, тормоза, рулевое управление, D/N/R, ограничитель скорости и аварийные лампы остаются независимыми.
- На заводской CAN сначала только пассивное наблюдение. Отсутствие `send()` в Python само по себе не обеспечивает электрический listen-only.
- Никакие цвета проводов, распиновки, резьбы датчиков и CAN ID для этой машины ещё не подтверждены. Предварительная схема из чата — не монтажная инструкция.
- Русский интерфейс; сначала телефон/браузер, постоянный экран опционален. Телефон — терминал; выбранное направление главного компьютера — Linux.
- Физическая разведка автомобиля пока не выполнена. Продолжение должно идти конкретными проверяемыми шагами без повторного изобретения уже зафиксированных решений.
- Все существенные решения, исправления, тесты и неопределённости — в GitHub, а не только в ответе ассистента.
- Секреты, GPS-треки, личные идентификаторы и частная телеметрия не входят в обычный исходный репозиторий.

## Насколько можно полагаться на эту точку

Смотрите фактический SHA ветки `main`, свежие workflow `CI` и `Repository audit`, а не номер версии в старом сообщении. Детальные проверки и оставшиеся риски описаны в отчёте аудита. Пороговые числа в диагностических правилах пока являются **порогами прототипа**, а не подтверждёнными сервисными пределами двигателя.

GitHub хранит инженерное содержание доступного чата, но не является обещанием побитового архива всех прежних вложений и всех внешних сайтов. Для оригиналов используйте реестр источников. Чат для продолжения разработки не должен требоваться; уникальные оригинальные файлы следует хранить отдельно, если они перечислены как не включённые.
