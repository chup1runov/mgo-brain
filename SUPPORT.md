# Support

MGO Brain is an experimental community engineering project, not a commercial support service or certified automotive diagnostic product.

## Where to ask

- **Bug or reproducible software problem:** open a GitHub issue using the bug template.
- **Feature / engineering work:** use the engineering-task template.
- **Candidate CAN signal:** use the CAN signal report template and include reproducible evidence.
- **Security/privacy issue:** follow [SECURITY.md](SECURITY.md) and do not post secrets or exploit details in a public issue.

## Vehicle safety

Do not rely on GitHub issues for urgent vehicle-safety decisions. OEM warnings and normal service/inspection procedures remain authoritative for operation of the vehicle.

A proposed CAN mapping, diagnostic threshold, wiring point or sensor fitment is not considered confirmed merely because it appears in an issue or discussion.
